# Brand

- `hero.png` — 3D badge render. Use for: social preview, docs landing, launch post.
- `mark.svg` — flat scalable mark derived from the hero (ring in `currentColor`,
  accent `#3B82C4`). Use for: favicon, GitHub org/repo avatar, README header,
  badges, dark/light themes, anywhere small.

Accent blue: `#3B82C4`. Wordmark: "DataCharter" (one word, capital D + C).
Tagline: "Charter your data."
